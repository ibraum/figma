# Figma-inspired Landing Page

A playful landing page designed in Figma and developed with Vue.js.

The project focuses on translating a visual concept into a functional web interface while preserving the original design, layout, and interactions.

## Overview

This project was created as a design and frontend development exercise, combining UI design with Vue.js implementation.

The interface uses a grid-based layout, colorful typography, floating elements, and interactive components to create a visual experience inspired by modern design tools.

## Features

- Responsive landing page
- Grid-based visual layout
- Playful typography and colors
- Interactive navigation elements
- Promotional banner
- Reusable Vue.js components
- Design-to-code implementation

## Tech Stack

- Vue.js
- JavaScript
- HTML
- CSS
- Figma

## Design Process

**Design → Structure → UI → Development → Responsive adaptation**

The interface was first designed in Figma, then translated into a functional Vue.js implementation.

## Purpose

The goal was to practice the transition from a high-fidelity UI design to a working frontend while maintaining visual consistency and attention to detail.
